Wireframes & layout flow

The page structure, the three user journeys it is built around, and blueprint-style wireframes for desktop and mobile. Read top to bottom; the page reads the same way.

A / Page flow

One long voyage, eight stops

A single scrolling page. Every section answers one buyer question, in the order a freight or ship-agency buyer asks them.

  1. 00HeroWho are you and where do you reach? Live route map from Penang, two CTAs (estimate, network).
  2. 01Who we areWhy trust you? The "we board ships" positioning plus four proof counters.
  3. 02ServicesWhat can you move? Ocean / Air / Land explorer with mode profile meters and door-to-door chain.
  4. 03Port agencyWhat does an agent actually do? Scroll-driven port call in six stages.
  5. 04The GroupWho will I deal with? Four companies as four containers with opening doors.
  6. 05NetworkDo you go where I go? Interactive lane map by mode, with transit time and distance.
  7. 06Instant estimateWhat will it cost? Four-step calculator ending in a firm-quote request.
  8. 07HeritageWill you be around? 1978 to today as a draggable horizon line.
  9. 08CTA + footerHow do I start? Quote or appoint-as-agent, signal-flag sign-off.

D / Interaction notes

States worth designing

Lane map

  • Idle: all lanes faint, hub radar pulse
  • Hover / focus: tooltip + lane brightens
  • Selected: lane draws in orange, marker sails it, panel fills
  • Land mode: viewBox zooms to the peninsula with a finer coastline

Calculator

  • Mode cards drive destination list and cargo fields
  • Live visual per mode: container fill, chargeable-weight bars, trailer pallet slots
  • Invalid fields flagged inline; Enter advances
  • Result hands a summary into the enquiry form

Port-call story

  • Scroll progress maps to ship position
  • Stage 3: cranes work, boxes lift off and reload
  • Stage 5: "Cleared" stamp lands
  • Reversible: scrolling up replays it backwards

Accessibility

  • Real tabs and radio groups with arrow-key support
  • Every map port is also a button in a list
  • Reduced-motion users get the static end state
  • Light "chart paper" and dark "night watch" themes
